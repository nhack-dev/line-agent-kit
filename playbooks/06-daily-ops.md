# 06 毎日・毎週の運用

## 毎日（10分）

```bash
python3 scripts/check_setup.py --online
python3 scripts/admin.py stats
```

オーナーへの知らせ（3行まで）の例:

```
友だち 128（+4）・ブロック 9（+0）・今月の残り 61通（あと4日で約40通使う見込み）
送れなかった便 0件
アンケートで「献立」を選んだ人が先週の倍。献立の便を1本足す案があります
```

## 毎週

1. ブロックが増えた日の前日の便を読み直す（長すぎ・売り込みが強い・時刻）
2. タグの数から、次に作る便／教材を1つ提案する
3. キーワードに当たらなかった問い合わせが多い言葉を、オーナーに聞いて keywords に足す
   （Worker は本文を保存しないので、オーナーが OA Manager のチャットで見た言葉を教えてもらう）
4. `build_flow.py --friends <先週の増え方×4>` で来月の見積もり

## 毎月

- 月初にプランの枠と先月の使用数を並べてオーナーへ（上げる／下げる／そのまま の案）
- 台帳の控え: `npx wrangler d1 export line-agent-kit --remote --output=backup-YYYYMM.sql`（git に入れない）
